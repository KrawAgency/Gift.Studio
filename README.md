# Gift Studio

Selector de regalos para invitar huéspedes a la presentación de UVC. Se usa en tablet o celular, cara a cara con el huésped.

- **Abrir:** https://krawagency.github.io/Gift.Studio/
- **Instalar como app:** en Chrome (Android), menú ⋮ → *Agregar a pantalla de inicio*.
- **Modo vendedor:** mantener presionado el título 1.2 s (o tecla `V`).

## Archivos
- `index.html` — toda la app (HTML, CSS y JS en un solo archivo).
- `img/` — fotos optimizadas (WebP); se descargan solo cuando aparecen en pantalla.
- `manifest.json` + `icon-*.png` — para instalarla como app.
